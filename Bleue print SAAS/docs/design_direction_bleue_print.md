# Direction artistique — BLEUE PRINT

## Plan compact

### 1. Palette
- Bleu de calque : #0F3D63
- Blanc papier : #F7F8FA
- Encre nuit : #0B1220
- Acier : #5B6B7C
- Signal vert : #1F7A5C
- Ambre discret : #B8863B

### 2. Typographie
- Display : grotesque géométrique, sans fioritures, poids medium/semibold
- Texte courant : humaniste lisible, très robuste à petite taille
- Données : monospace pour codes SH et montants

### 3. Layout
- Grille stricte, marges généreuses, beaucoup de blanc
- Structure claire, faible décor, zéro cliché SaaS générique
- Les lignes de cotation ne servent qu’à décomposer le calcul

### 4. Signature visuelle
- Le total final se présente comme une coupe technique
- Les taxes s’empilent visuellement : droit → RS → PC → TVA → total
- Le mot “blueprint” s’exprime via cette couche de calcul, pas via un motif décoratif

## Vérification anti-générique
Cette direction évite les trois défauts signalés :
- pas de fond crème / terracotta
- pas de noir profond avec accent fluo
- pas de broadsheet dense et décoratif

La proposition reste fidèle au sujet : précision technique, confiance institutionnelle, document bien construit.
